# Security Policy

## Supported Versions

Security fixes are provided for the latest release of MacPacker.

## Reporting a Vulnerability

Please report security vulnerabilities privately through
[GitHub Security Advisories](https://github.com/sarensw/MacPacker/security/advisories/new).

Please include the affected version, steps to reproduce, and any
relevant sample files. Do not open a public issue for undisclosed
security vulnerabilities.
